HOW IT WORKS

Four hops. All standard.

The source VM is never modified. The artifact is a plain qcow2 plus a manifest.

STRAIGHT TALK

What this does and doesn't prove.

Proven

  • The Prism v4 export path, end to end, in code
  • qcow2 and manifest produced, valid, converted
  • Boots on KVM and on KubeVirt, unattended
  • Repeatable: rerun it and get the same result

Not yet

  • A real Nutanix cluster (Prism here is a simulator)
  • Windows, UEFI, multi-disk and large VMs (h2kvm's scope)
  • Guest repair: it was skipped on this Alpine image
  • Anything deeper than ping inside the guest

Run it yourself.

$ git clone https://github.com/zyvorai/zyvor-transiva
$ ./scripts/e2e-nutanix-exit.sh user@your-kvm-host

Needs a Linux host with libvirt, hyperexport, h2kvmctl and the Chimera Nutanix service. KubeVirt is detected and used when present.
